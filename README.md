# PikaMaxxing plugin

Claude Code plugin for [PikaMaxxing](https://pikamaxxing.vercel.app):
your token usage raises pokemon that live in your Mac's notch or menu bar.

```
/plugin marketplace add idobry/pikamaxxing-plugin
/plugin install pikamaxxing@pikamaxxing
/pikamaxxing:setup
```

The hooks are safe no-ops until you link your Mac from your trainer page
(that step installs the PikaMaxxing app itself).

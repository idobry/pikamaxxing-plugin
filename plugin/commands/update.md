# PikaMaxxing update

Bring the PikaMaxxing plugin up to date:

1. Run `claude plugin marketplace update pikamaxxing` in the shell, then
   `claude plugin update pikamaxxing@pikamaxxing`.
2. Tell the user to run `/reload-plugins` (or start a new session) so the
   updated mod loads. Their trainer link, team and settings are kept.
3. Report the version it moved to, or that it was already current.
